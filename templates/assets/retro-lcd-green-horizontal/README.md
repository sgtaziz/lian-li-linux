# Retro LCD / Green

Classic reflective green LCD dashboard for the Universal Screen 8.8-inch, horizontal 1920×480. Shares the Retro LCD catalog card with Amber; select Green before installing.

Includes a seven-segment 24-hour clock, seconds, date, weekday, CPU/GPU temperatures and usage, and RAM usage bars. Confirm the five sensor categories during catalog installation. Eight sensor-bearing widgets retain portable sensor_category hints; installation resolves these to selected sources. Do not copy the portable JSON directly into the installed configuration.

Original static green faceplate and bezel. No commands or network access are needed for playback. Bundled DSEG7 Classic Bold and Rajdhani SemiBold fonts require no system installation. See CREDITS.md for licenses.

preview.png is generated by the native renderer with simulated sensor values. The contributor tested this green variant on a physical display connected to their PC.
